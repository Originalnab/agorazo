# AGORAZO FRONTEND PRD

## Progressive Web Automotive Marketplace

**Product:** Agorazo  
**Tagline:** Buy. Sell. Drive.  
**Frontend Type:** Responsive Progressive Web Application  
**Primary Experience:** Mobile-first automotive marketplace  
**Secondary Experience:** Tablet and desktop web platform  
**Target Market:** Ghana initially  
**Primary Users:** Vehicle buyers, dealers, suppliers, clearing partners and Agorazo administrators

---

# 1. Frontend Vision

Agorazo should feel like a premium automotive application rather than a traditional classifieds website.

On mobile, the experience should resemble an installed native application.

Users should be able to:

- Install Agorazo to their phone home screen
- Browse cars quickly
- Save vehicles
- Compare vehicles
- Request cars
- Receive quotations
- Make payments
- Track installment progress
- Track imported vehicles
- Access documents
- Communicate with sellers
- Manage their purchases

On larger screens, the same product should transform into a spacious, high-end automotive marketplace.

The interface should communicate:

**Speed**

**Trust**

**Premium automotive commerce**

**Transparency**

**Modern technology**

---

# 2. Design Direction

Agorazo should use a modern automotive marketplace aesthetic.

The chosen Agorazo identity uses:

- Burnt orange / copper
- Dark charcoal
- White
- Warm off-white
- Neutral grey

The frontend should use orange selectively for:

- Primary CTA
- Active navigation
- Price highlights
- Progress indicators
- Important status elements
- Brand accents

Dark charcoal should be used for:

- Text
- Header elements
- Premium cards
- Footer
- Selected dashboard areas

The interface should avoid excessive orange.

Vehicle photography should remain the dominant visual element.

---

# 3. Design Personality

The platform should feel:

- Premium
- Fast
- Clean
- Trustworthy
- Automotive
- Sophisticated
- Modern
- Simple to navigate
- Professional
- Financially credible

Avoid:

- Excessive gradients
- Gaming-style interface
- Overly futuristic UI
- Excessive shadows
- Small text
- Dense information
- Cheap classified-ad appearance
